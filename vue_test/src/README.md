总结TodoList案例
1.组件化编码流程:
    (1).拆分静态组件: 组件要按照功能点划分, 命名不要与html元素冲突
    (2).实现动态组件: 考虑好数据的存放位置，数据是一个组件在用，还是一些组件在用:
        1).一个组件在用: 放在组件自身即可
        2).一些组件在用: 放在他们共同的父组件上(抽象化)
    (3).实现交互: 从事件绑定开始
2.props适用于:
    (1).父组件==>子组件 通信
    (2).子组件==>父组件 通信 (需要父组件先传给子组件一个数据处理的函数)
3.使用v-model时要切记, v-model绑定的值不能是props传过来的值,因为props不可进行修改
4.props传过来的对象, 修改该对象的成员属性不会被检测到, 但是不推荐
